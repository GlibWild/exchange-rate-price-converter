# 汇率价格转换器（Edge 扩展）

自动识别网页中的价格与货币单位，并在原价后面用插件中选择的目标货币显示换算结果。

## 功能

- 自动识别常见价格写法：`$12.99`、`US$1,299`、`1,234.56 USD`、`€1.234,56`、`￥89`、`12.5 元`、`1.2万美元`、`100円`、`Rp 150.000` 等。
- 支持符号、ISO 代码（USD / EUR / CNY …）、中文名称（美元 / 欧元 / 日元 …）以及 `万`、`亿`、`million`、`billion`、`k`、`M`、`B` 等数量级。
- 弹窗中通过下拉框选择目标货币，设置立即保存并应用到已打开的页面。
- 汇率每 6 小时自动更新；离线时可使用本地兜底汇率（会明确标注）。
- 动态加载的内容（无限滚动、单页应用）会自动补扫。
- 同一页面可随时点击「重新扫描」强制重新识别。

## 安装（Microsoft Edge）

1. 打开 Edge，地址栏输入 `edge://extensions/`。
2. 打开右下角「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择本目录（包含 `manifest.json` 的文件夹）。
4. 打开任意商品或价格页面，点击工具栏中的扩展图标，选择「换算为」的目标货币即可。

> 如果工具栏没有显示图标，请在扩展列表中点击「显示在工具栏」。

## 使用说明

| 设置项 | 说明 |
| --- | --- |
| 启用开关 | 关闭后页面上的换算标注会立即移除 |
| 换算为 | 目标货币，可选项来自 `currencies.js` |
| 小数位 | 换算结果保留 0–4 位小数 |
| 原货币与目标货币相同时不显示 | 勾选后不再显示同币种冗余标注 |
| 刷新汇率 | 立即从 open.er-api.com 获取最新汇率 |
| 重新扫描 | 通知所有已打开页面重新识别价格 |

## 目录结构

```
manifest.json      扩展清单（Manifest V3）
background.js      后台 Service Worker，获取并缓存汇率
content.js         内容脚本，扫描页面并插入换算结果
content.css        页面内标注样式
parser.js          价格识别与金额解析（纯函数，可单测）
currencies.js      货币定义（代码 / 中文名 / 符号）
popup.html/css/js  工具栏弹窗
demo/index.html    本地演示页（双击打开时需开启扩展的「允许访问文件网址」）
tests/             parser.js 单元测试
icons/             扩展图标
```

## 开发与测试

```bash
node tests/parser.test.js
```

修改 `parser.js` 的价格识别规则后，请同步补充 `tests/parser.test.js` 中的用例。

## 已知限制

- 仅识别同一个文本节点内的「货币 + 金额」组合。若货币符号与数字被拆分成不同元素（如 `<span>$</span><span>12.99</span>`），可能无法识别。
- `$`、`¥`、`kr` 等存在歧义的符号会结合页面语言（`<html lang>`）与域名后缀判断，仍可能有个别误判。
- 兜底汇率是静态参考值，仅用于在线接口不可用时的展示，实际汇率请以银行或支付渠道为准。
- 换算标注为页面内即时计算，不改变页面原有价格，也不会自动下单或填写表单。

## 隐私

- 扩展不收集、不上传任何浏览记录或页面内容。
- 仅向 `open.er-api.com` 请求公开汇率数据。
- 设置保存在浏览器同步存储中，汇率缓存在本地存储中。
